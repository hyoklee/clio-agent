# Provider artwork

`ndp-light.png` and `ndp-dark.png` are the unmodified National Data Platform
horizontal marks (650 × 114), reused from the CLIO UI's provider logo assets.
The dark asset is the white version. `NdpBrand.astro` chooses the mark using
the website's current theme.

Official sources:

- https://nationaldataplatform.org/wagtail/media/original_images/National_Data_Platform_horiz_stacked.png
- https://nationaldataplatform.org/wagtail/media/original_images/National_Data_Platform_horiz_stacked_wt.png

Do not redraw or recolor the logos.
